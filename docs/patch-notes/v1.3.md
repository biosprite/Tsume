# Tsume v1.3

## New Features

### Acer Predator Atlas 8 (Beta)
- Added beta support for the Acer Predator Atlas 8. PredatorSense must be paused in Settings for Tsume to work correctly (it is automatically restored if Tsume is uninstalled).

### Custom Fan Curves & Profiles
- Added custom fan curves with up to three profiles, real EC fan duty percentages, live tachometer RPM readings, and built-in thermal safety floors tailored to each chipset.
- Moved fan controls to the **Fans** page under **Customization** in **Settings**, replacing the old Max fan mode with custom profiles.
- Updated the **Fans** quick tile (and the **Cycle fan mode** button action) to cycle through Auto and your configured custom profiles, displaying the active profile's name.
- Added inline profile renaming inside the Fans page (with automatic Windows touch keyboard handling when no physical keyboard is attached), plus the option to reset custom profile names back to default.

### OptiScaler & Frame Rate Limiting
- Exposed **OptiScaler's built-in low-latency frame rate limiter** in per-game settings and defaults (which pairs better with frame generation than RTSS), with a **VRR** preset that calculates a cap for your display's refresh rate (also available in RTSS).
- Added an **Auto-install in all games** toggle in OptiScaler defaults to automatically install OptiScaler into all eligible games using your default settings (skipping games with anti-cheat).
- Added a note in the RTSS Frame Rate Limit section recommending OptiScaler's limiter when using OptiScaler.
- Improved manually added custom games so they reuse store and folder detection for cleaner game names and install locations.

### CPU Boost Quick Tile
- Added an opt-in **CPU Boost** quick tile (enable it under Quick Tiles customization) to toggle CPU Turbo Boost on or off from the main panel. It is recommended to leave CPU Boost on for G3 chips.

## Bug Fixes & Other Changes
- Removed the panel's opening fade-in animation so it opens faster.
- Fixed a brightness flash when toggling RGB lighting groups by keeping global brightness steady.
- Fixed an RTSS overlay text alignment leak on boxed overlay layers, and updated RTSS version detection to check the Windows registry first so point releases report accurately.
- Fixed minor UI glitches: Hardware Discovery extending past the display work area, the battery charge limit selector animating from 100% when opening Settings, and the clipped OptiScaler anti-cheat button.
- Improved controller polling reliability and gated the WinMM input fallback to Xbox Full Screen Experience.
- OptiScaler now verifies file hashes for all installed files and writes rollback manifests incrementally so interrupted installs can still be cleanly reversed.
- Cleaned up OptiPatcher wording and made the OptiScaler game page header more compact.
