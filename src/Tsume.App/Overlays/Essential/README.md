# Essential overlays

The overlay layouts and atlas images in this folder are the **Essential** (Dark) RTSS overlays
(1920×1200) by **realHfde** (Faisal), from
[Huffdee RTSS Overlays and Rainmeter Skins](https://github.com/realHfde/Huffdee-RTSS-Overlays-and-Rainmeter-Skins),
used under the MIT License (see `LICENSE` in this folder).

Tsume merges all four Dark layouts into a single combined OverlayEditor layout
(`essential_tsume.ovl`) with one stitched atlas (`essential_tsume_atlas.png`) via
`tools/build-overlays.ps1`. RTSS's OverlayEditor plugin draws the layout and reads most sensors
through its built-in HAL, while Tsume publishes the active level (`TSUME_OVERLAY_LEVEL`), position
(`TSUME_POS_X`/`Y`), and fallback EC temperature / RAPL power readings over `AIDA64_SensorValues`.
That lets Tsume switch levels (including Off) and placement live without ever restarting RTSS
(preventing mid-game DX12/Vulkan hook crashes), and hides the overlay automatically when Tsume
exits.

| Tsume level | Source layout                    |
|-------------|----------------------------------|
| 1 — FPS     | `essential_fps` (made by Tsume from Essential Sleek) |
| 2 — Bar     | `essential_sleek`                |
| 3 — Detail  | `essential_sleek_compact`        |
| 4 — Full    | `essential_performance_overlay`  |

The stitched atlas is `1943×1804`, leaving `244 px` of vertical headroom inside RTSS's shared
`2048×2048` Raster 3D font+atlas texture so font charsets are never overwritten, and stays well
within OverlayEditor's 256-layer limit (`84` layers).

## Changes from the originals

- The frame rate, 1% low and 0.1% low sources that read MSI Afterburner were removed. OverlayEditor
  then uses its built-in RTSS sources of the same names, so Afterburner is not needed.
- `essential_fps.ovl` is new. It reuses Essential Sleek's panel (its two rounded ends and the middle
  section) and its FPS and 1% low fields.
- `essential_tsume.ovl` and `essential_tsume_atlas.png` are generated by `tools/build-overlays.ps1`:
  they merge all four Dark levels into one layout, rework the Bar, Detail and Full layouts (plus
  their panel chrome) for single-chip handheld PCs so each displays one shared chip temperature
  reading instead of duplicating CPU/GPU temperatures and discrete VRAM temperature, pack the
  resized panel backgrounds with 145-frame anti-aliased CPU/GPU rings (2.5° per frame, replacing
  the 51-frame / 7.2° originals) animated at 30 FPS (`RefreshPeriod=33` with two-stage critically
  damped `HAL/Timer` EMA smoothing) while all hardware sensors stay strictly at RTSS's standard
  `1000 ms` cadence (with Tsume also shifting `<P=x,y>` directly in shared memory for instant
  next-frame drag/drop movement), gate each level's layers with `VisibilitySource` on
  `TSUME_OVERLAY_LEVEL` (`x == 1..4`), compute live rolling `1% low` and `0.1% low` from RTSS's
  1,024-frame `Frametime` ring buffer (refreshed every 1 s, no benchmark hotkey needed), and add
  AIDA64 fallbacks for temperature, CPU/GPU power, and CPU clock when OverlayEditor's HAL reports
  them blank.

The combined layout locks its master font to `Segoe UI` Bold (`-14`, `ZoomRatio=1`) and uses only
RTSS's native `100%` and `200%` Raster 3D charsets (`14 px` and `28 px`) so every label and figure
maps 1:1 to screen pixels without bilinear font scaling blur.
