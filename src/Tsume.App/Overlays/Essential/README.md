# Essential overlays

The overlay layouts and atlas images in this folder are the **Essential** RTSS overlays
(1920×1200) by **realHfde** (Faisal), from
[Huffdee RTSS Overlays and Rainmeter Skins](https://github.com/realHfde/Huffdee-RTSS-Overlays-and-Rainmeter-Skins),
used under the MIT License (see `LICENSE` in this folder).

Tsume merges the four layouts for each theme into a single combined OverlayEditor layout
(`essential_tsume*.ovl`) with a stitched atlas (`essential_tsume*_atlas.png`) via
`tools/build-overlays.ps1`. RTSS's OverlayEditor plugin draws the layout and reads most sensors
through its built-in HAL, while Tsume publishes the active level (`TSUME_OVERLAY_LEVEL`) and
fallback EC temperature / RAPL power readings over `AIDA64_SensorValues`. That lets Tsume switch
levels (including Off) live without restarting RTSS, and hides the overlay automatically when
Tsume exits.

| Tsume level | Source layout                    |
|-------------|----------------------------------|
| 1 — FPS     | `essential_fps` (made by Tsume from Essential Sleek) |
| 2 — Bar     | `essential_sleek`                |
| 3 — Detail  | `essential_sleek_compact`        |
| 4 — Full    | `essential_performance_overlay`  |

Each combined layout comes in the Dark, Smoke, White and Float themes (`essential_tsume.ovl`,
`essential_tsume_smoke.ovl`, `essential_tsume_white.ovl`, `essential_tsume_float.ovl`).

## Changes from the originals

- The frame rate, 1% low and 0.1% low sources that read MSI Afterburner were removed. OverlayEditor
  then uses its built-in RTSS sources of the same names, so Afterburner is not needed.
- `essential_fps*.ovl` is new. It reuses Essential Sleek's panel (its two rounded ends and the middle
  section) and its FPS and 1% low fields.
- `essential_tsume*.ovl` and `essential_tsume*_atlas.png` are generated by `tools/build-overlays.ps1`:
  they merge all four levels into one layout per theme (staying within OverlayEditor's 256-layer
  limit), stitch the three unique atlases vertically with offset sprite Y coordinates, gate each
  level's layers with `VisibilitySource` on `TSUME_OVERLAY_LEVEL` (`x == 1..4`), compute live
  rolling `1% low` and `0.1% low` from RTSS's 1,024-frame `Frametime` ring buffer (refreshed every
  1 s, no benchmark hotkey needed), and add AIDA64 fallbacks for CPU/GPU temperature, CPU/GPU power,
  and CPU clock when OverlayEditor's HAL reports them blank.

The layouts look best with the [Inter](https://rsms.me/inter/) font installed. Without it, RTSS
substitutes another font.
